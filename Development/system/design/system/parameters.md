# Design parameters (internal)

These internal values guide implementation; [system requirements](../../requirements/system-requirements.md) define acceptance. Candidate values remain proposals until measured. Keep parameter IDs in configuration and evidence. Clip format (P04), replay fidelity (P14) and amplifier sizing (P16) are outside the required scope.

Owners are the logical components in the [module map](interfaces-and-behavior.md#static-dependency-and-module-map). COMMUNICATION owns setup/retry budgets; PORTAL owns page limits; WIFI owns radio operation limits.
