# Audio detailed design

[Interfaces and behavior](interfaces-and-behavior.md) define the `L1_I2S` service boundary, the
`L2_AUDIO` block loop, stream configuration, sizing, Start and Stop order and fault handling of the
first audio path. The [AUDIO architecture](../../architecture/AUDIO/README.md) defines the
responsibilities; the shared [system parameters](../system/parameters.md) P01, P02, P03 and P11
hold the values.
