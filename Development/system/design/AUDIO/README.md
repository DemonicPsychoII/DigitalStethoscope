# Audio detailed design

[Interfaces and behavior](interfaces-and-behavior.md) define the `L1_I2S` service boundary, the
`L2_AUDIO` block loop and states, stream configuration and rationale, sizing, Start and Stop order
and fault handling of the audio path. The views are PlantUML sources in this folder, rendered to
[rendered/](rendered/) and embedded in the document. The
[AUDIO architecture](../../architecture/AUDIO/README.md) defines the responsibilities. The shared
[system parameters](../system/parameters.md) P01, P02, P03 and P11 hold the values.
