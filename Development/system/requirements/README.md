# Requirements

The [use-case flows](use-cases.md) show the operator flows. The [system requirements](system-requirements.md)
list each requirement with its test and pass criterion.

A requirement states an outcome that is testable on the finished device with the equipment listed
in the [system requirements](system-requirements.md).

Requirement IDs are stable: an edited requirement keeps its ID, and an ID is not reused. Each
requirement has an anchor of the form `system-requirements.md#req-09`.
